# Battle music (placeholder)

Every fight picks one track at random from this folder (`.mp3`, `.ogg` or
`.wav`; set in `data/config/audio_events.tres` → `battle_music_dir`).

The tracks here now are **reference beatbox tracks the user has no rights to**.
They are gitignored: local play only, never commit or ship them. With the
folder empty, fights fall back to the synth floor pulse.
